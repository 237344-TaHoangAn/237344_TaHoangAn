## 2. Giới thiệu
Dự án xây dựng hệ thống quản lý nhân sự, hỗ trợ quản lý thông tin nhân viên, tìm kiếm, thêm mới, cập nhật và xóa hồ sơ nhân viên.

## 3. Công nghệ sử dụng
- **Frontend:** React, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Quản lý mã nguồn:** Git, GitHub
- **Đóng gói ứng dụng:** Docker, Docker Hub
- **Triển khai:** Render

## 4. Cấu trúc dự án
- `frontend/`: mã nguồn giao diện người dùng.
- `backend/`: mã nguồn API và xử lý nghiệp vụ.
- `.gitignore`: các tệp và thư mục không đưa lên Git.
- `README.md`: tài liệu mô tả dự án.

## 5. Hướng dẫn chạy dự án
### Backend
1. Mở terminal tại thư mục `backend/`.
2. Chạy `npm install`.
3. Tạo tệp `.env` từ `.env.example` và cấu hình biến môi trường.
4. Chạy `npm start`.

### Frontend
1. Mở terminal tại thư mục `frontend/`.
2. Chạy `npm install`.
3. Chạy `npm run dev`.
4. Mở địa chỉ localhost được Vite hiển thị trong terminal.

*Lưu ý: Các lệnh chỉ hoạt động sau khi mã nguồn và các tệp cấu hình tương ứng được tạo đầy đủ.*
